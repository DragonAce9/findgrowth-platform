Править этот файл: меняй текст после двоеточия, не переименовывай поля. Чтобы добавить страницу или блок — копируй пустой шаблон ниже.

- Дата среза-примера: 1 сентября 2026, Atelier
- Единица смысла: уже заплаченное (€) и следующий заказ
- Текст ИИ на экране — по SMART (S / M / A / R / T)

---

## Как пользоваться

1. Сначала пройди **меню** и **хозяев факта** — если страница не нужна, поставь в «Статус»: `убрать`.
2. У каждой страницы заполни или поправь: задача, кто, порядок, статус.
3. У каждого блока заполни или поправь семь полей.
4. Новая страница: скопируй «Пустой шаблон страницы». Новый блок: скопируй «Пустой шаблон блока» внутрь страницы.
5. Статус страницы: `оставить` / `сжать` / `перенести` / `новая` / `убрать`.
