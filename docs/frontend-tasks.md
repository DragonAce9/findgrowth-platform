# Задачи разработки web-интерфейса FindGrowth

Дата: 9 октября 2026. Статус: **бэклог, код не менялся, коммитов нет.**
Источники: `docs/frontend-requirements.md` (req §) и `docs/ux-design-spec.md` (spec §). Список идентичен канвасу `findgrowth-front-backlog` по идентификаторам и содержанию; статус задач ведётся в канвасе.

Стек: Next 15 App Router, React 19, TypeScript; экраны — серверные компоненты в `src/app/`, движок — `src/engine/`. UI на русском, код на английском. Все пути и номера строк — по коду на дату документа.

Обозначения: **effort** S / M / L; **приоритет** P0 / P1 / P2; **DOR** — задача ждёт движок или решение владельца, фронт делает свою часть по имеющимся данным и подписывает отсутствующее словами; префикс `[движок]` / `[оба]` — не только фронт; `[владелец]` — ждёт решения владельца продукта.

Всего 54 задачи: P0 — 22, P1 — 26, P2 — 6. С DOR — 11 (из них ждут движок 7, ждут владельца 2, подпись мер каталога 1, формат файла 1).

1. **Типы.** `npx tsc --noEmit` в корне — 0 ошибок после каждой задачи.
2. **Тесты.** `npm test` (после F6.2 / F7.2 скрипт — `tsx --test "src/**/*.test.{ts,tsx}"`): голден-тесты копирайта (F6.1), статический рендер kit (F6.2), лексический тест (F6.3), тест контраста (F7.2). Каждый новый assert должен падать на старом коде — проверять до правки и записывать в PR.
3. **Браузер.** Dev-сервер на свободном порту, **не 3000** (`npx next dev -p 3100`; процесс на 3000 не трогать). Три среза аудита: Atelier `asOf 2026-09-01`, «Второй срез» `2027-01-15` (run `c_0e9cd67dd71702d3f9febe4e`), косметика `2020-02-29`. Пять экранов (Неделя, Бриф, ТЗ, Студия, Каталог) × 1280 и 897 px, плюс 360 px для прокрутки SVG. Скриншоты — в `/tmp/fg-ux-after/`, не в репозиторий. Чеклист — req §8.
4. **Печать.** Бриф и ТЗ → PDF в ч/б: статусы читаются по маркеру и слову, у `.verdict` и чипов рамка, ключи не печатаются (дефолт F8.1).
5. **Контраст.** Только по отчёту теста F7.2 (пары spec §2.2, порог 4,5 для текста и 3 для заливок), не на глаз.
